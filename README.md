## 真实性能：老 CPU 是常态，还有节点运气

RackNerd 的短板在 CPU 代次。它的 VPS 节点以 Xeon E5/E3 这类老型号为主，第三方测试显示 Geekbench 5 单核得分多在 400–600 之间，和新一代云 CPU（比如 Vultr 高频线同项测试 1100 以上）有明显差距。

更大的变量是节点运气。一家测评站对比过它手上的两台测试机：布法罗节点（Xeon E5-2690 v4）Geekbench 6 单核跑出 910 分，达拉斯节点（Xeon E5-2690 v2）只有 414 分——同一家提供的机器，单核性能差了一倍多。所以别只看「几核 vCPU」就下单，两个老核心和两个新核心是完全不同的体验。

关于超售：内存不超售，买多少就是多少；CPU steal（被邻居虚拟机偷走的时间）在高峰期偶尔达到 5–10%；硬盘是普通 SSD 组 RAID-10，不是 NVMe，跑代理、轻量网站没问题，高频数据库 I/O 会成为瓶颈。

收到机器之后建议按这个顺序做一遍检查：

1. 跑一次 YABS，留下 CPU、磁盘、网络的基准数据
2. 高峰时段开着 top 或 htop，观察 steal 数值
3. 从你的用户所在地区跑 MTR，看丢包和路由质量
4. 用 fio 测磁盘，确认没有异常慢
5. 挂外部监控跑满 24 小时，再考虑把正经流量迁进去

结果明显异常就保留原始数据开工单，直接问是否可以迁移节点——便宜不是慢得离谱的理由。
